# Support

Use the [issue tracker](https://github.com/ddoug220/kyle-reese/issues) for reproducible bugs and focused feature requests.

Before opening an issue:

1. Run `npx kyle-reese --help` to confirm the command syntax.
2. Run the audit with `--json` and save the relevant function result.
3. Reduce the problem to the smallest source file that still reproduces it.
4. Remove secrets and proprietary code from the example.

Questions about a private codebase should use a small synthetic example. Security issues must follow [SECURITY.md](SECURITY.md).
